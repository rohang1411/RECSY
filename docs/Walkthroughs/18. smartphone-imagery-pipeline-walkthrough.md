# Walkthrough — Extensible Studio Smartphone Imagery Pipeline

Resolved the missing and unpolished smartphone photo issue across RECSY by implementing an automated, multi-tier studio media pipeline that downloads, hosts, and serves clean official product renders locally from `public/phones/` at $0 cost.

## Summary of Changes

### 1. Extensible Studio Media Resolver

**File:** [`src/services/catalog/studio-media-resolver.ts`](file:///c:/Users/rohan/Documents/RECSY/mobile_recommender/src/services/catalog/studio-media-resolver.ts)

- Built a multi-tier resolution engine that resolves clean, official studio product renders for any smartphone:
  - **Tier 1 (Curated Registry):** Known clean studio render URLs for catalog mainstays.
  - **Tier 2 (Pattern Candidate Generation):** Algorithmic kebab-case / alias generator targeting official studio CDN patterns (`fdn2.gsmarena.com/vv/bigpic/...`).
  - **Tier 3 (Dynamic Brand Catalog Crawler):** For new/unseen future models, crawls maker brand listings (Apple, Samsung, Google, Xiaomi, OnePlus, Motorola, Nothing, Vivo, Honor, Sony) without Cloudflare Turnstile interference.
  - **Tier 4 (OEM Page Extractor):** Falls back to manufacturer `og:image` / JSON-LD product art if official URLs are present.
  - **Tier 5 (Normalized Wikimedia Commons):** Upgrades `http:` to `https:` and handles redirects if only crowdsourced media exists.
- **Local Download Pipeline:** `downloadAndSavePhoneImage()` validates the remote stream, downloads the image to `public/phones/${slug}.jpg`, computes SHA-256 hashes, updates `phones.image_url = '/phones/${slug}.jpg'`, sets `phones.media_status = 'local_ok'`, and upserts durable metadata in `phone_media_assets`.

### 2. Standalone Automation Script

**Files:** [`scripts/catalog-backfill-gsmarena-images.ts`](file:///c:/Users/rohan/Documents/RECSY/mobile_recommender/scripts/catalog-backfill-gsmarena-images.ts) & [`package.json`](file:///c:/Users/rohan/Documents/RECSY/mobile_recommender/package.json)

- Added `pnpm catalog:backfill-images` command.
- Supports flags: `--slug <slug>`, `--limit <n>`, `--force`, `--dry-run`.
- Automatically inspects the catalog and downloads missing studio renders.

### 3. Automatic Future Ingestion Integration

**File:** [`scripts/catalog-backfill-media.ts`](file:///c:/Users/rohan/Documents/RECSY/mobile_recommender/scripts/catalog-backfill-media.ts)
