# Implementation Plan — Studio Smartphone Imagery Pipeline (Solution B + A)

Automate the acquisition and local hosting of clean, official studio smartphone renders for 100% of the phones in the RECSY catalog, eliminating missing photos, amateur user shots (fingers/reflections), and external CDN dependencies at $0 cost.

## User Review Required

> [!IMPORTANT]
>
> - **Local Asset Hosting:** Images will be saved directly to `public/phones/[slug].jpg`. The total size for all 21 phones is ~1.5 MB (~70 KB per image), introducing virtually zero repository bloat while providing instant local loading, PWA/offline compatibility, and immunity to remote CDN hotlinking blocks.
> - **Database Updates:** `phones.image_url` will be set to `/phones/[slug].jpg`, `phones.media_status` will be set to `local_ok`, and entries will be upserted into `phone_media_assets`.
> - **Browse Card Presentation:** On `src/app/browse/page.tsx`, the card image fit will be adjusted from `fit="cover"` to `fit="contain"` with subtle padding. Studio renders look significantly more premium when the entire phone silhouette is visible rather than cropped into the frame.

## Proposed Changes

### 1. Catalog Scripts & Automation (Solution B)

#### [NEW] [scripts/catalog-backfill-gsmarena-images.ts](file:///c:/Users/rohan/Documents/RECSY/mobile_recommender/scripts/catalog-backfill-gsmarena-images.ts)

A standalone, production-ready script that:

- Reads active/upcoming phones from the database (or seeds).
- Uses a deterministic phone-to-image resolver with fallback to GSMArena brand-page indexing to obtain clean, high-res studio renders for each device.
- Fetches each image, validates the image buffer, and writes it to `public/phones/[slug].jpg`.
- Computes SHA-256 content hashes.
- Updates `phones.image_url = '/phones/[slug].jpg'` and `phones.media_status = 'local_ok'`.
- Records durable asset tracking in `phone_media_assets` (`storage_path`, `public_url`, `sha256`, `is_primary = true`, `status = 'active'`).
- Supports CLI flags: `--dry-run`, `--force`, `--limit`.

- Add script entry: `"catalog:backfill-images": "tsx --env-file=.env.local scripts/catalog-backfill-gsmarena-images.ts"`
